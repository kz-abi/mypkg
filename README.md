# PID制御シミュレータ
![test](https://github.com/kz-abi/mypkg/actions/workflows/test.yml/badge.svg)

PID制御シミュレータです。

## 概要
ROS 2を用いて、1次遅れ系のプラントをPID制御するシミュレーションパッケージです。
Launchファイルによる複数ノードの起動を実装しています。

## ノード
* `plant`
  * 1次遅れ系の物理モデルをシミュレートするノードです。
  * コントローラからの入力値を受け取り、現在の状態量（出力値）を計算して送信します。
* `controller`
  * PID制御を行うコントローラのノードです。
  * プラントの出力値を受け取り、目標値（50.0）に近づけるための操作量を計算して送信します。

## トピック
* `/current_val`
  * 型: `std_msgs/msg/Int16`
  * プラントの現在の出力値（状態量）です。
* `/count_up`
  * 型: `std_msgs/msg/Int16`
  * コントローラからプラントへ送られる操作量です。

## 実行方法
1. Launchファイルを使用して、制御対象（plant）とコントローラ（controller）を同時に起動します。

```bash
$ ros2 launch mypkg mypkg.launch.py
```

2. 別の端末で以下のコマンドを実行することで、制御値が目標値（50.0）に向かって収束していく様子を確認できます。
```bash
$ ros2 topic echo /current_val
```

## テスト環境
GitHub Actionsを用い、以下の条件でテストを自動化しています。
実際の制御結果が目標値である50に十分収束したこと（49〜50の範囲に入ったこと）を確認しています。

* **テストスクリプト**: `test/test.bash`
* **テスト内容**: Launchファイルを起動し、15秒以内にトピック `/current_val` の値が `50.0` を含む状態になるかを確認します。

ローカルでテストを実行する場合：
```bash
$ cd test
$ bash test.bash
```
